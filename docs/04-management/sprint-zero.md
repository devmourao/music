# Sprint Zero — VJ Lab

## Objective

Prepare the environment, repository, documentation structure and working standards before Sprint 1. No product features are mandatory in Sprint Zero.

## Checklist

* [x] Repository created with `main` branch
* [ ] Branch strategy recorded (`feature/<id>-<description>`, `fix/`, `docs/`, `release/`)
* [ ] Project structure aligned with approved architecture (audio engine, director store, stage scenes, audio bus)
* [ ] Tool versions recorded (Node, Vite, React, Three.js)
* [ ] Test runner installed with first smoke test passing (`npm test`)
* [x] Documentation site structure ready (`docs/` with business, architecture, design, management)
* [ ] Naming, Conventional Commits, Pull Request and Code Review standards recorded
* [ ] Backlog reviewed; Sprint 1 candidates identified (VJLAB-01 to VJLAB-03)

## Standards Applied

* Branches: `feature/<id>-<description>` for features, `fix/` for defects, `docs/` for documentation.
* Commits: `<type>(<scope>): <description>` in English, one logical change per commit.
* Pull Requests: single purpose, linked issue, checklist (build, tests, lint, docs when applicable), review before merge.
* Definition of Done: implemented, compiling, tests executed, review approved, merged, docs updated, acceptance criteria met.

## Sprint 1 Proposal

* Goal: blank 3D stage at 60 FPS with green quality gate.
* Candidates: VJLAB-01, VJLAB-02, VJLAB-03.
* To be refined in Sprint Planning.
