## 2. Executive Summary

Live Control release: the MVP becomes a playable desk with A/B dissolve transitions, per-preset palettes, damped zoom, per-effect intensity, image textures, animated text, tunable strobe and a VHS/RGB/beat-flash effects pack.

## 3. New Features

* Dissolve transitions with tunable duration plus instant hard cut.
* Palette system: per-preset backgrounds with global hue rotation.
* Damped continuous zoom and four dry/wet mix slots with master fader.
* PNG/JPG texture layer on the deformable mesh with load feedback.
* Editable animated text overlay fired live.
* Strobe speed control (1–12 Hz).
* Global effects: VHS glitch, RGB split, beat flash (all kill-switch safe).
* ABNT2-safe letter shortcuts with visible mix bars.

## 4. Improvements

* Zero per-frame allocations in mesh deformation (precomputed normals).
* Unlit textured mode preserves uploaded artwork colors.
* 36 automated tests, lint-clean, green gate on every merge.

## 5. Fixes

* Missing `postprocessing` peer dependency resolved.
* Silent texture-load failures now surface load status.
* Private framework untracked from the public repository.

## 6. Known Limitations

* Heavy effect stacks may hitch on GPUs without dedicated memory (lite mode planned).
* RGB split is intentionally subtle; local files only; desktop keyboard recommended.
