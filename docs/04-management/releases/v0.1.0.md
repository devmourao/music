## 2. Executive Summary

First public release of VJ Lab: a browser-based VJ instrument that turns a local .mp3 into live 3D visuals. Six presets across three base scenes, keyboard direction, global effects and a data-driven architecture ready for future engine ports.

## 3. New Features

* Local .mp3 upload with managed Web Audio playback.
* Real-time FFT spectrum engine (bass, mids, treble normalized with smoothing).
* Three base scenes: particle field, deformable mesh, light tunnel.
* Six presets as pure data (palette, gain, speed) on the shared scene contract.
* Playlist navigation (keys 1–6, N/P).
* Keyboard desk: strobe with warning, burst impulse, camera nudge, instant kill switch.
* Global post-processing (bloom + vignette).

## 4. Improvements

* Pure DSP and scene math isolated and unit tested (21 tests).
* Per-frame data flows through refs; UI state stays out of the render loop.

## 5. Fixes

* Installed missing `postprocessing` peer dependency found during the effects sprint.

## 6. Known Limitations

* Desktop browser with WebGL2 and keyboard recommended; no mobile layout yet.
* Local files only; no DJ routes or system capture in this version.
* Static single-page build; no user accounts or persistence.
