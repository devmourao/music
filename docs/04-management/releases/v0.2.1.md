## 2. Executive Summary

Polish release: strobe flash modes, honest color knobs, ABNT2-safe keymap, portfolio identity and lite mode for weak GPUs.

## 3. New Features

* Strobe modes white/black/preset-color with always-visible status.
* Saturation and contrast slots with true library neutrals.
* Clickable mix-bar rows; letter aliases E/R/F alongside symbol keys.
* Version seal, About panel (I/Esc) and lite mode (L) from a single metadata source.

## 4. Improvements

* Burst impulse rewired into all scenes; shortcuts ignored while typing.
* Dead ReactiveCube component removed; mesh normals precomputed.
* Unlit textured mode preserves uploaded artwork; texture load status shown.
* 45 automated tests, lint-clean, green gate on every merge.

## 5. Fixes

* Black-screen defaults corrected (contrast divide-by-zero, saturation scale).
* Private framework untracked; React pinned for clean installs.

## 6. Known Limitations

* Heavy effect stacks may hitch on GPUs without dedicated memory (lite mode mitigates).
* RGB split intentionally subtle; local files only; desktop keyboard recommended.
