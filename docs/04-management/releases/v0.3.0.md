## 2. Executive Summary

Stage Control release: panel visibility modes, fullscreen output, auto-pilot tour and a fully readable desk HUD with industry-aligned strobe reinforcement, without breaking any existing shortcut.

## 3. New Features

* Panel visibility modes — docked / detached popup / hidden cycled via U (free, verified) with popup fallback.
* Fullscreen output — native F11 plus G alias with safe exit and hidden-panel coordination.
* Auto-pilot tour — A toggles timed palette / camera / zoom / scene tour with pause and post-processing guardrail.
* Desk status pills and mode color — VHS/RGB/BEAT/BYPASS/LITE/AUTO and strobe mode as color-coded pills.
* Transport mini-bars — strobe Hz, zoom, hue and transition duration as bars reusing mix-track.

## 4. Improvements

* Desk grouping — STROBE / TRANSPORT / FLAGS sections, burst badge, master duplication removed.
* Strobe color reinforcement — swatch, glow and Hz bar tint per mode (white/black/color) without photosensitive animation.
* Shortcut label polish — R/F ABNT2 note clarified and S formatting restored; desk status line as pills.
* Keyboard ergonomics review vs Resolume/VDMX documented, no overwrite, reserves Q/W/M for future mixer.

## 5. Fixes

* Post-chain freeze when combining VHS and chromatic aberration isolated in its own EffectGroup (VJLAB-35).

## 6. Known Limitations

* Detached popup is a placeholder with fallback floating panel; full BroadcastChannel sync is next iteration.
* Auto-pilot uses fixed 5s interval; not yet audio-synced.
* Heavy effect stacks may hitch on weak GPUs (lite mode mitigates).
